Site editor

Sign in with a GitHub access key to change text, pictures and video on the site.

  1. Open GitHub → New access key. The name and permission are filled in for you.
  2. Choose an Expiration (for example 90 days), scroll down and press Generate token.
  3. Copy the key that starts with ghp_ and paste it below.

Another editor? Add them on GitHub under the repository's Settings → Collaborators. They then make their own key here.
